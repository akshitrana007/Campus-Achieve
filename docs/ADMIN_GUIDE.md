# Teacher/admin quick guide

1. Open `/admin` on the college portal.
2. Sign in using the initial admin credentials provided securely by college IT.
3. Change the temporary password when prompted.
4. The dashboard contains only the students table:
   Registration No. | Name | Year of Passing | Semester | Certificates
5. Select `View (n)` in a row to open that student's certificate list. Use `View` to open a short-lived private file link.
6. Log out on shared computers.

Only authorized college administrators should receive admin credentials. Contact IT to update the official roster or disable an account.
